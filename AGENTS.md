# Working agreement for AI agents in this repo

This repo is career evidence for Ryan Hamby. Every public claim must be backed
by dated, verifiable work. Follow these rules in every session:

1. Quote no number (README, docs, posts) unless it comes from a captured run:
   `pow run NAME -- CMD` saves the command, raw output, and hardware info to
   `results/`. Name the hardware. If results differ across machines, say so.
2. Commit in small, meaningful steps. Never squash a feature's history into one
   commit. Never disable commit signing.
3. After a meaningful decision, experiment, failure, or dead end, run
   `pow log "what was tried, what happened, what was decided"`. Keep failures.
4. Keep the README's "How this was built" section accurate about AI assistance.
5. Don't invent results, dates, or metrics. If two sources disagree (README,
   resume, site), flag it and ask instead of picking one.
